Package "com.tauntastic.syntypacks" (assembly Tauntastic.SyntyPacks.Editor, namespace Tauntastic.SyntyPacks.Editor, depends on com.tauntastic.webbrowser, editor-only): a window (titled "Synty Packs", menu Tools > Tauntastic > Synty Packs, class SyntyPackWindow) that lists the Unity packs of the public Synty store catalog and what the user has done with them. SyntyCatalog downloads syntystore.com/products.json (cached in Library, refreshed every "hours between refreshes", Products with ProductType used as category and LatestUnityVersion read from the change log), SyntyInstalledScanner finds imported packs by folder name under Assets, packs in the Unity Asset Store cache and downloads, and SyntyProduct.SameName compares pack names by their identifying words (case, punctuation, plurals and the words Pack, Free and "Art by Synty" are ignored). Ownership flags come from SyntyMyAssets (reads the signed-in Unity account's My Assets list through reflection into the Package Manager's internal UnityEditor.PackageManager.UI.Internal services, which may break in other Unity versions; the scan is saved in Library for the refresh interval), from the Synty library file read by SyntyStoreLibrary (JSON with "packs"; default SyntyStudios/SyntyStoreLibrary.json in the user folder; filled by SyntyLibraryImporter, which opens the Synty store library in a Tauntastic.WebBrowser WebBrowserWindow with the browser profile "SyntyStore" and reads the pack names with the page's own sign-in) and from downloads in the downloads folder. Asset Store packs are downloaded and imported with SyntyMyAssets.Install, Synty store packs with SyntyStoreDownloader.DownloadAndImport, which finds the pack's page in the library, picks the Unity file for the current Unity version (SyntyUnityFileChooser) and downloads it with WebBrowserSession.DownloadAsync before opening Unity's import window. The version of every pack this package downloads is known (SyntyUnityFileChooser.ParseVersion reads it from the Synty file entry name such as "| v1_7_3", SyntyMyAssets.GetLocalVersion reads it from the Asset Store cache) and SyntyImportTracker.Expect(packagePath, handle, version) must be called right before AssetDatabase.ImportPackage so that the version is recorded as installed (SyntySettings.SetRecordedVersion) when Unity reports the import finished, never when it is cancelled or failed. SyntyProjectWatcher (an AssetPostprocessor) tells the window to rescan when project files change, and a pack whose folder disappears loses its recorded version; SyntyProduct.FindIn matches a pack to its folder by name (a trailing Kit, Pack or FREE of the title is ignored because Synty names the folder of "POLYGON - Snow Kit" PolygonSnow). Settings are EditorPrefs keys starting with "SyntyStudios.Packages." (the prefix is kept from the package's former name) and a preferences page under Tools/Tauntastic/Synty Packs; the window state (categories, ownership filter, collapsed rows, search) is saved there too. The package never stores passwords or cookies, and it has no runtime code, so never reference it from runtime assemblies.
