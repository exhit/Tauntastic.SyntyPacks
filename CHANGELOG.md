# Change Log:

## 1.0.0

- First release as `com.tauntastic.syntypacks` (formerly `com.syntystudios.packages`): Synty store catalog, project and Asset Store cache detection, update flags, Packs window with category and ownership toolbars (All, Animation, Polygon, Simple Series, ...; Polygon only by default), preferences, collapsible rows, automatic ownership flags (In Project, Not Owned, Own In Asset Store, Own In Synty Store, Own Unknown), My Assets (Asset Store purchases) read through Package Manager internals, and Download & Import, saved scans, Synty store library file with an in-Unity browser import (Tauntastic.WebBrowser) Synty store downloads, automatic recording of the downloaded version, and a window that follows the project (imports and deletions).
